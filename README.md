# BindOptiX
PhotoKinX ist eine GPU-beschleunigte C++/CUDA-Multiphysik-Engine mit Python-Anbindung, die als digitaler Zwilling für optische Biosensoren Mikrofluidik, aktive Kraftfelder, thermo-optische Effekte und biochemische Bindungskinetik nahtlos mit wellen- und strahlenoptischen Solvern zur holistischen Sensoroptimierung koppelt.
